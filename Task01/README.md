## Структура файлов данных

В каталоге `Task01` находятся следующие файлы:

'genres.txt' - список жанров фильмов 
'movies.csv' - movieId, title, genres (информация о фильмах)
'occupation' - перечень профессий
'ratings.csv' - userId, movieId, rating, timestamp (оценки пользователей)
'ratings_count.txt' - минимальный и максимальный userId с количеством строк 
'sqlite3.txt' - версия SQLite и доступные режимы вывода
'tags.csv' - userId, movieId, tag, timestamp (теги, присвоенные пользователями фильмам)
'users' - данные о пользователях (userId, name, email, gender, birthdate, occupation)
'README.md' - этот файл с описанием структуры
